# 🌆 CitySphere  

CitySphere is a local marketplace and city guide that connects **newcomers and residents** with local vendors, artisans, bookstores, and service providers.  

---

## ✨ Features  
- City selection (manual + GPS)  
- Category browsing (Bakers, Artisans, Bookstores, Groceries, etc.)  
- Vendor profiles with products, photos, contact, and address  
- Google Maps integration for shop location and directions  
- WhatsApp deep-link chat with vendors  
- Reviews & ratings  
- Vendor registration and admin approval  
- Secure payments via Razorpay/Stripe  

---

## 🏗️ Tech Stack  
- Frontend: React.js, React Native  
- Backend: Node.js + Express  
- Database: MongoDB  
- APIs: Google Maps, Cloudinary/S3, WhatsApp deep link, Razorpay/Stripe
